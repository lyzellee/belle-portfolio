Sentinel project carousel images

Add up to 27 project screenshots to this folder.

Supported formats:
- PNG
- JPG / JPEG
- WebP
- AVIF

Recommended filenames:
01-dashboard.png
02-requests.png
03-alerts.png
04.png through 27.png

Name the images in the order you want them to appear. The carousel sorts
filenames naturally, so numbers 1 through 27 are displayed in the correct order.
